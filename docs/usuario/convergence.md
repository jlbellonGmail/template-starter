# Convergencia autónoma

F04 permite que Builder corrija findings concretos y que Reviewer vuelva a
validar el estado actual hasta aprobar, escalar una decisión material,
detenerse por un bloqueo externo o fallar de forma segura.

El ciclo es proporcional a ASSESS/SDD: LIGHT es breve, STANDARD cubre la
corrección normal y FULL admite más profundidad. El resultado siempre informa
la iteración, findings abiertos/resueltos, progreso, motivo de detención y
próxima acción. No se agregan agentes ni se exige un proveedor específico.
