# Skills

Vacío a propósito. Este es el punto de extensión canónico para Agent
Skills portables (ver `AGENTS.md`, sección "`.agents/skills/`"). Las
copias en `.claude/skills/` y `.opencode/skills/` se regeneran desde
acá vía `scripts/sync-agentic-adapters.ps1` — no se editan a mano.

Cada proyecto real que use este template agrega sus propias skills en
esta carpeta cuando las necesite; el template en sí no define ninguna.
